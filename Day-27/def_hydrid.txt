-------------Hybrid inheritance
is when a Python program uses more than one inheritance pattern together.
------------or
combination of two or more types of inheritance 

For example, 
this program combines hierarchical, multiple, and multilevel inheritance:

-----------code

class Employee:
    def work(self):
        print("Employee works")
class Developer(Employee):
    def code(self):
        print("Developer writes code")
class Tester(Employee):
    def test(self):
        print("Tester tests software")
class TechLead(Developer, Tester):
    def lead(self):
        print("Tech Lead leads the team")
t = TechLead()

t.work()
t.code()
t.test()
t.lead()

              /      \
       Developer     Tester
              \      /
